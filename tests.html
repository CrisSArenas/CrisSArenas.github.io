Tested math

Model tests

All financial math on this site lives in one file, pm-math.js, and every demo calls it. Each function is tested against a known answer: a hand calculation, an identity the model must satisfy, or a round trip. The tests below run in your browser now. The same file runs from Node with node tests/run.js.

When the math moved out of the original demos and into the library, it was checked against the old code before the old pages were retired: 2,298 of 2,298 compared values identical (tests/legacy-proof.js), and the portable alpha tab of the Multi-Strategy Builder shows the same 210 of 210 figures as the original simulator page at three seeds (tests/pa-page-proof.mjs).
