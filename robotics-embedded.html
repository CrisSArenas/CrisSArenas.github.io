Autonomous Navigation

ROS 2 Nav2 Simulator

Full-stack ROS 2 Navigation Stack (Nav2) simulator implementing A* path planning, costmap inflation layers, behavior tree execution, and AMCL-based localization. Demonstrates the complete autonomous navigation pipeline from goal pose to velocity commands with real-time obstacle handling and recovery behaviors.

  • ROS 2
  • Nav2
  • A* Path Planning
  • Behavior Trees

FreeRTOS Kernel Simulator

Implements the FreeRTOS fixed-priority preemptive scheduler with round-robin time slicing, a configurable tick rate, and running, ready, blocked and suspended state transitions. Presets walk through unbounded priority inversion, the mutex priority inheritance that fixes it, and an overloaded task set that misses deadlines, with CPU utilization shown against the rate-monotonic bound and a Gantt view that matches the kernel log line for line.

  • FreeRTOS
  • Preemptive Scheduling
  • Context Switching
  • RTOS Internals
Open the simulator → Perception & Mapping

SLAM Mapping Simulator

Simultaneous localization and mapping driven by a simulated 360-beam LiDAR at 10 Hz with realistic range and bearing noise. Builds a log-odds occupancy grid at 5 cm resolution from a 300-particle Monte Carlo localization estimate, so you can drive the robot and watch the filter hold its track while raw odometry drifts away. Live position error and map coverage are charted. No loop closure or pose-graph back end, and the page is explicit about what that costs.

  • SLAM
  • LiDAR Simulation
  • Monte Carlo Localization
  • Occupancy Grids

STM32 Memory-Mapped I/O Lab

Register-level STM32 peripheral control without HAL abstractions. Directly manipulate GPIO MODER/ODR/IDR registers, configure alternate function mappings, set up interrupt vectors via NVIC, and control USART/SPI peripherals through raw memory-mapped addresses on the ARM Cortex-M bus.

  • STM32
  • ARM Cortex-M
  • Register-Level I/O

TinyML Model Quantization Lab

Neural network compression pipeline for microcontroller targets. Apply post-training INT8/INT4 quantization, analyze per-layer accuracy degradation, compare FP32 vs quantized inference latency, and validate that models fit within SRAM/Flash constraints of Cortex-M class devices before deployment.

Autonomous Mobile Robot

Differential-drive robot built from scratch on a Raspberry Pi 4 running ROS 2 Humble. C++ nodes for an RPLiDAR A1, a BNO055 IMU and encoder-fed motor control feed Cartographer SLAM, and Nav2 plans and drives with live obstacle avoidance.

  • ROS 2
  • Nav2
  • Cartographer
  • RPLiDAR A1
  • BNO055

Edge ML Inference on STM32

INT8 image classifier on an STM32H743 (Cortex-M7, 480 MHz) with TensorFlow Lite Micro. Bare-metal C drivers capture OV7670 frames over DCMI with double-buffered DMA and draw results on an SPI display, all inside 512 KB of SRAM.

  • TF Lite Micro
  • STM32H7
  • DCMI + DMA
  • INT8 quantization
  • Bare-metal C

Real-Time Sensor Fusion & Balance Controller

Self-balancing platform on an ESP32 under FreeRTOS. Complementary and Kalman filters fuse MPU-6050 gyro and accelerometer data, and a cascaded PID controller runs the angle loop at 100 Hz and the position loop at 20 Hz from ultrasonic distance.
